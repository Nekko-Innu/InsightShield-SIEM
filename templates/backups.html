Restoring runs from the server shell, with both services stopped so nothing holds the database open. Click Restore on a row to copy the full command: it stops both services, restores as the insightshield user (a root-owned database file stops the app from booting), then starts them again. The current database is kept as insightshield.db.pre-restore.bak. Encrypted snapshots are integrity-checked on restore. A row marked Plaintext — unverified is not, and restoring one needs an explicit --allow-plaintext — its contents cannot be told apart from a planted file.

Restore from backup

Paste into an SSH session on the server. The dashboard goes offline until the last line finishes; alerts that arrived after this backup was taken are lost. 

sudo systemctl stop insightshield insightshield-worker
cd /opt/insightshield/insightshield
sudo -u insightshield /opt/insightshield/venv/bin/python -m backup restore backups/
sudo systemctl start insightshield-worker insightshield
